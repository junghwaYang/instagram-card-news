# 2시간 강의 커리큘럼: "AI가 일하게 하라 — 빈 폴더에서 시작하는 인스타 카드뉴스 자동화"

## 강의 콘셉트

**한 줄 요약**: 빈 폴더에서 AI(Claude Code)에게 설계도를 주고, 나만의 카드뉴스 자동 생성 공장을 0부터 100까지 직접 짓는 과정을 마스터한다.

**대상**: 코딩 경험 없는 마케터, 콘텐츠 크리에이터, SNS 운영자, 1인 사업자 — 나만의 자동화 시스템을 소유하고 싶은 분

**수강 후 가져가는 것**:
1. 빈 폴더에서 5분 만에 구축하는 "나만의 카드뉴스 자동 생성 시스템"
2. AI 두 명이 토론하며 품질을 높이는 "AI 협업 시스템"의 원리
3. 디자이너 없이도 브랜드 색깔을 입히는 "디자인 템플릿 커스터마이징" 기술

## 비개발자 용어 사전

강의 중 사용되는 어려운 용어들을 쉬운 말로 바꿨습니다.

- **AI 총감독** (Orchestrator): 전체 과정을 지휘하고 각 AI에게 일을 시키는 메인 AI
- **자동화 흐름** (Pipeline): 자료 조사부터 이미지 생성까지 정해진 순서대로 일이 진행되는 과정
- **이미지 생성/변환** (Rendering): AI가 만든 글자를 예쁜 디자인 틀에 넣어 그림 파일로 만드는 작업
- **AI 역할/담당자** (Agent): 팩트체커, 카피 작가 등 특정 임무를 맡은 AI
- **이미지 변환 도구** (Puppeteer): 웹 화면을 사진으로 찍어주는 기술적 도구
- **설계도** (Bootstrap Prompt): 빈 폴더에 공장을 짓기 위해 AI에게 주는 전체 구조 지시서
- **정해진 양식** (Data Contract): AI들끼리 정보를 주고받을 때 약속한 데이터 형태
- **빈칸** (Placeholder): 디자인 틀에서 글자가 들어갈 자리
