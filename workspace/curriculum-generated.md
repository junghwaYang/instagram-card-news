목차

강의 콘셉트

한 줄 요약: 프롬프트 한 줄로 Instagram 카드뉴스 10장을 자동 생성하는
시스템을 직접 만들며, AI 에이전트 오케스트레이션의 핵심 패턴을 체득한다.

대상: Claude Code를 사용해본 적 있거나, AI 코딩 도구에 관심 있는
개발자/마케터/콘텐츠 크리에이터

수강 후 가져가는 것:

1.  실제 동작하는 카드뉴스 생성기 (본인 계정에 바로 사용 가능)

2.  CLAUDE.md로 AI를 오케스트레이터로 만드는 메타 패턴

3.  멀티 에이전트 토론 시스템 설계 경험

프로젝트 기술 개요

프로젝트: Instagram 카드뉴스 자동 생성기

핵심 컨셉: \"한 줄 입력 → 완성된 카드뉴스 PNG 10장\" --- Claude Code가
AI 오케스트레이터 역할

**기술 스택**

- Node.js + Puppeteer (HTML → PNG 렌더링)

- Claude Code (CLAUDE.md 기반 파이프라인 오케스트레이터)

- HTML+CSS 템플릿 시스템 (8스타일 x 14타입 = 112개 템플릿)

- Team 모드 에이전트 토론 (copywriter + hook-expert)

**5단계 파이프라인**

1.  Step 1: 요청 파싱 (topic, tone, slide_count, accent_color,
    account_name)

2.  Step 2: 리서치 (Task 에이전트 → workspace/research.md)

3.  Step 2.5: 리서치 검증 (팩트체커 + 보완리서처 병렬 실행)

4.  Step 3.5: 카피 토론 (Team 모드 --- copywriter + hook-expert,
    SendMessage로 실시간 토론, 후킹점수 7점 이상 합의)

5.  Step 4: 렌더링 (Puppeteer --- node scripts/render.js →
    output/\*.png)

6.  Step 5: 시각 검토 (PNG 읽어서 가독성/잘림/흐름/CTA 검토)

**렌더링 파이프라인**

- slides.json 읽기 → 각 슬라이드의 type에 맞는
  templates/{style}/{type}.html 로드 → {{placeholder}} 치환 →
  Puppeteer로 1080x1350px 스크린샷 → PNG 저장

- applyPlaceholders() 함수가 30+ 플레이스홀더를
  string.split().join()으로 치환

**템플릿 시스템**

- 8개 스타일: clean, minimal, bold, elegant, premium, toss, magazine,
  blueprint

- 14개 슬라이드 타입: cover, content, content-badge, content-stat,
  content-quote, content-image, content-steps, content-list,
  content-split, content-highlight, content-grid, content-bigdata,
  content-fullimage, cta

- 각 템플릿은 완전한 self-contained HTML 문서 (외부 의존성 없음)

**Team 모드 토론 시스템 (Step 3.5)**

- TeamCreate(team_name=\"copy-debate\") → 카피작가 + 후킹전문가 스폰

- 라운드 1\~3: 카피작가 초안 → 후킹전문가 평가(1\~10점) → 피드백 반영
  수정 → 재평가

- 합의 기준: 후킹점수 7점 이상 + 양측 합의

- 최대 3라운드, 실패 시 마지막 버전 채택
